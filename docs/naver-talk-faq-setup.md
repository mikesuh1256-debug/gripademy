# 네이버톡톡 선택형 FAQ 연결 안내

## 완성된 대화 구조

- 상담·등록
  - 상담등록 절차
  - 상담신청서
  - 평일 상담
- 수업·수강료
  - 학년별 시간표
  - 과목별 시간표
  - 초중등 수강료
- 학원·학생관리
  - 주소·주차
  - 학생관리시스템
  - 학생·과목 문의

각 최종 답변에는 `상담신청`, `이전메뉴`, `처음으로` 버튼이 표시된다. 사용자가 수강료, 주차, 상담시간 등의 핵심어를 직접 입력해도 관련 답변을 보여준다.

## 배포 후 연결

1. 배포된 상태 확인: `https://megrip.com/api/naver-talk`
2. 네이버톡톡 파트너센터에서 해당 계정의 `개발자도구 > 챗봇API 설정`으로 이동한다.
3. Webhook의 이벤트 받을 URL에 다음 주소를 등록한다.
   - `https://megrip.com/api/naver-talk`
4. Webhook 이벤트에서 `open`, `send`를 선택한다.
5. `echo` 이벤트는 선택하지 않는다. 답변이 반복 전송되는 것을 막기 위해서다.
6. 저장 후 톡톡 사용자 화면에서 아래 순서로 테스트한다.
   - 채팅방 입장 시 대분류 메뉴 3개 표시
   - 각 대분류의 질문 3개 작동
   - 9개 답변의 이전메뉴·처음으로 작동
   - 상담신청 버튼이 `https://megrip.com/apply`로 이동

## 선택 사항: Webhook 주소 보호

Vercel 환경변수에 `NAVER_TALK_WEBHOOK_TOKEN`을 추가하면 URL의 `token` 값이 같은 요청만 허용한다.

예시:

`https://megrip.com/api/naver-talk?token=Vercel에_등록한_긴_임의문자열`

토큰은 코드나 문서에 실제 값을 적지 않는다.

## 문구 수정 위치

FAQ 제목, 키워드, 답변은 `lib/naver-talk-faq.js`의 `ANSWERS`에서 관리한다. 자주 쓰는 문구와 챗봇 API의 답변은 자동으로 동기화되지 않으므로, 운영 문구를 바꿀 때 두 곳을 함께 수정한다.
